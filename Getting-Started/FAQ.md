# FAQ

**Is this a cheat mod?**
No. Dismantles refund what the game refunds, a Copy costs the full build cost, and a Move is free
only because the originals are taken in exchange. The one convenience is that Save Blueprint does
not need the Blueprint Designer. With the game's No Build Cost on, Regionator follows the game's
rule.

**Can I remove the mod safely?**
Yes. Everything it builds is a normal building, and its blueprints are normal blueprint files. If
your save has not reached the blueprint milestone, see [Save Blueprint](Save-Blueprint) first.

**Why did my Move leave some buildings behind?**
A belt or power line with one end outside the selection stays, and an original whose copy cannot
be verified is kept rather than destroyed. See [Move](Move).

**Why is my Copy red after Snap to Origin?**
It is sitting on its own originals. Nudge it off; see [Snap to Origin](Snap-To-Origin).

**Why does a Copy or Save Blueprint skip the HUB or the Space Elevator?**
They can only be built once. A Move still moves them.

**Does it work in multiplayer?**
Yes, tested on a dedicated server; see [Multiplayer](Multiplayer).

**Does it work on a controller?**
Yes, fully; see [Controller and Steam Deck](Controller).

**Is it translated?**
Into all 26 of the game's languages.

**Where do refunds go?**
Targeted containers first, then your inventory, then a crate. See
[Container Targeting](Container-Targeting).

**Can I save while an operation is running?**
Yes. Items the operation has taken out but not yet handed back (cleared items, refunds, belt items
on their way) go into the save as a crate, so loading that save loses nothing. The game you are
playing is not affected. A save during a [Move](Move) waits a moment for the originals to be
removed.

**How big can a selection be?**
35000 buildings, inside a 500 x 500 x 500 m space, by default. Both can be raised in the Mods
menu; see [Limits and Known Issues](Limits-And-Known-Issues).

**Why is my region red, and why does confirm do nothing?**
The selection is over the volume limit. Shrink it, or raise **Selection volume limit factor** in
the Mods menu.

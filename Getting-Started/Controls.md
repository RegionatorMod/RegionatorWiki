# Controls

All keys can be rebound under **Options > Keybindings > Regionator**. Controller chords are
explained on [Controller and Steam Deck](Controller).

| Action (as the options menu names it) | Keyboard | Controller |
|---|---|---|
| Regionator: equip tool | `J` | `L3 + LB` |
| Regionator: filter building types | `L` | `L3 + X` |
| Regionator: target hovered container | `Left Alt` (tap) | `L3 + RB` |
| Regionator: add region | `Left Ctrl + N` | `L3 + A` |
| Regionator: toggle region shape (box / sphere) | `Left Ctrl + B` | `L3 + Y` |
| Regionator: snap to origin | `Left Ctrl + H` | `L3 + R3` |
| Regionator: mark auto pillars | `Left Ctrl + P` | `L3 + LT` |
| Switch Build Mode (picks the nudge target; listed on the controller page) | the build-mode key | `L3 + B` |

Everything else uses the game's build gun controls: primary fire places and confirms, secondary
fire steps back, the build-mode key cycles the tool mode or the nudge target, and lock, nudge and
rotate work as on any hologram.

## Notes

- The `Left Ctrl` chords only apply while the tool, a blueprint hologram or the dismantle tool is
  in hand. Without `Left Ctrl`, `N`, `B`, `H` and `P` do what the game normally does.
- The container key acts on a quick tap. Holding `Alt` with anything else, such as `Alt` + click,
  does not target.

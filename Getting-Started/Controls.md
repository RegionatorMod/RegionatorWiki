# Controls

All keys live in the game's options menu under **Options > Keybindings > Regionator** and can be
rebound, including to a mouse button or a two-key chord. On a controller every command is a
chord on the left stick click, because no pad button is free while a hologram is up; apart from
equip, the chords only count while the tool, a blueprint hologram or the dismantle tool is in
hand, so elsewhere those buttons stay the game's. See [Controller and Steam Deck](Controller).

| Action (as the options menu names it) | Keyboard | Controller |
|---|---|---|
| Regionator: equip tool | `J` | `L3 + LB` |
| Regionator: filter building types | `L` | `L3 + X` |
| Regionator: target hovered container | `Left Alt` (tap) | `L3 + RB` |
| Regionator: add region | `Left Ctrl + N` | `L3 + A` |
| Regionator: toggle region shape (box / sphere) | `Left Ctrl + B` | `L3 + Y` |
| Regionator: snap to origin | `Left Ctrl + H` | `L3 + R3` |
| Regionator: mark auto pillars | `Left Ctrl + P` | `L3 + LT` |
| Switch Build Mode (picks the nudge target; controller page only) | the build-mode key | `L3 + B` |

Mark auto pillars only works with **Enable auto pillars** on in the Mods menu (off by default),
in Save Blueprint and Copy, once the current region is finished; see [Auto Pillars](Auto-Pillars).

Everything else is the game's own build-gun controls, unchanged: primary fire places anchors and
confirms, secondary fire steps back or cancels, the build-mode key cycles the tool mode or the
nudge target, and lock, nudge and rotate work as they do on any hologram. On a controller the
locked region's D-pad nudges, so there the nudge target is picked with `L3 + B` instead. That
binding is listed under the game's own name, **Switch Build Mode**, on the controller page.

## Chords

The game's quick search stays on a plain `N`, its holster on a plain `H` and its photo mode on a
plain `P`. While the tool, a blueprint hologram or the dismantle tool is in hand and `Left Ctrl`
is held, `N`, `B`, `H` and `P` are the mod's; letting go of `Left Ctrl` gives them back. The same
applies to any chord you rebind to.

The container key on `Left Alt` acts on a quick tap: press it and let go. Holding `Alt` with
anything else, such as `Alt` + click to ping, leaves the containers alone.

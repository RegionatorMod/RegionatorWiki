# Controls

All keys live in the game's options menu under **Options > Keybindings > Regionator** and can be
rebound, including to a mouse button or a two-key chord. On a controller most of the mod's
commands sit in the game's build-mode menu instead, because no pad button is free while a
hologram is up; see [Controller and Steam Deck](Controller).

| Action (as the options menu names it) | Keyboard | Controller |
|---|---|---|
| Regionator: equip tool | `K` | Hotbar radial, build menu or quick switch |
| Regionator: filter building types | `U` | Build-mode menu: **Filter types** |
| Regionator: target hovered container | `Left Ctrl` | Build-mode menu: **Target container** |
| Regionator: add region | `Ctrl + N` | Build-mode menu: **Add region** |
| Regionator: toggle region shape (box / sphere) | `Ctrl + B` | No pad entry |
| Regionator: snap to origin | `Ctrl + H` | `L3 + R3` (hold `L3`, press `R3`) |

Everything else is the game's own build-gun controls, unchanged: primary fire places anchors and
confirms, secondary fire steps back or cancels, the build-mode key cycles the tool mode or the
nudge target, and lock, nudge and rotate work as they do on any hologram.

## Chords

The game's quick search stays on a plain `N` and its holster on a plain `H`. While `Left Ctrl` is
held, `N`, `B` and `H` are the mod's; letting go of `Left Ctrl` gives them back. The same applies
to any chord you rebind to.

## Rebinding notes

- Snap to origin is the one action with a controller key of its own. It appears on both the
  keyboard and the controller pages of the options menu, and each device's binding is changed on
  its own.
- Mouse buttons work as bindings.
- Resetting a binding restores the defaults above.

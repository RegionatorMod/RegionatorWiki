# Controls

All keys live in the game's options menu under **Options > Keybindings > Regionator** and can be
rebound, including to a mouse button or a two-key chord.

| Action (as the options menu names it) | Default |
|---|---|
| Regionator: equip tool | `K` |
| Regionator: filter building types | `U` |
| Regionator: target hovered container | `Left Ctrl` |
| Regionator: add region | `Ctrl + N` |
| Regionator: toggle region shape (box / sphere) | `Ctrl + B` |
| Regionator: snap to origin | `Ctrl + H` (pad: hold `L3`, press `R3`) |

Everything else is the game's own build-gun controls, unchanged: primary fire places anchors and
confirms, secondary fire steps back or cancels, the build-mode key cycles the tool mode or the
nudge target, and lock, nudge and rotate work as they do on any hologram.

## Chords

The game's quick search stays on a plain `N` and its holster on a plain `H`. While `Ctrl` is
held, `N` and `H` are the mod's; letting go of `Ctrl` gives them back. The same applies to any
chord you rebind to.

## Rebinding notes

- Snap to origin appears on both the keyboard and the controller pages of the options menu, and
  each device's binding is changed on its own.
- Mouse buttons work as bindings.
- Resetting a binding restores the defaults above.

See [Controller and Steam Deck](Controller) for the pad layout.
